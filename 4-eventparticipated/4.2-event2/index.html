Meeting 2

Report on the Mini Meetup – API Standards in Backend Development

1. Event Objectives

The Mini Meetup, held on August 22, 2026, was a knowledge-sharing event organized by the FCAJ community. The event focused on API standards in Backend development, helping participants better understand the role of APIs in building and developing modern software systems.

The main objectives of the event were:

  • To understand the role of APIs in connecting and exchanging data between system components.
  • To explore important standards and principles for designing Backend APIs.
  • To understand the importance of building APIs that are easy to use, maintain, and scale.
  • To encourage continuous learning, knowledge sharing, and professional development within the technology community.

2. Speaker and Topic

  • Nguyen Nhan – FCAJ Member: API Standards in Backend Development.

3. Key Topics

3.1. Overview of APIs in Backend Development

The first topic introduced APIs (Application Programming Interfaces) and their role in connecting applications and software components.

Key learning points included:

  • Understanding the concept of APIs and their role in software architecture.
  • Recognizing how APIs enable communication between applications and services.
  • Understanding the importance of designing APIs that are clear, consistent, and easy to use.
  • Recognizing the role of APIs in integrating components within larger systems.

Through this topic, I gained a better understanding of how APIs support communication between Frontend applications, Backend services, and other software systems.

3.2. API Design Standards and Principles

The second topic focused on important standards and principles for developing Backend APIs, with an emphasis on usability, maintainability, and scalability.

Key aspects included:

  • Consistency: Using consistent endpoint naming conventions, data structures, and response formats.
  • Usability: Designing clear endpoints that other applications and services can easily integrate with.
  • Maintainability: Organizing APIs logically to simplify updates, bug fixes, and the development of new features.
  • Scalability: Designing APIs with a structure that can accommodate future system growth.
  • Compatibility: Minimizing breaking changes that could affect applications already using the APIs.

These principles helped me understand that API development involves more than simply processing requests. It also requires attention to design quality and long-term maintainability.

3.3. The Role of APIs in Modern Systems

The final topic discussed the importance of APIs in connecting services and supporting integration within modern software systems.

Important considerations included:

  • Clearly defining the purpose of each endpoint and the data it needs to exchange.
  • Standardizing request handling, responses, and error messages.
  • Prioritizing authentication, authorization, and data protection when exposing APIs.
  • Considering API versioning when modifying or introducing new features.
  • Providing clear API documentation to support development and integration.

Through this topic, I recognized that well-designed APIs can reduce dependencies between components, support system integration, and make future development easier.

4. Knowledge and Skills Gained

4.1. Technical Knowledge

  • APIs and Backend Development: Gained a better understanding of the role of APIs in connecting software system components.
  • API Design: Recognized the importance of consistency, usability, and maintainability when designing Backend APIs.
  • System Integration: Learned more about how APIs facilitate communication and data exchange between applications and services.
  • API Security: Recognized the need for authentication, authorization, and data protection when developing service interfaces.
  • Scalability: Understood that API design should accommodate future system growth and changing requirements.

4.2. Personal Development Skills

  • Improved my ability to explore and learn new technical concepts.
  • Understood the value of sharing technical knowledge and practical experience within a technology community.
  • Gained further motivation to explore API design, documentation, and testing.
  • Recognized the importance of continuous learning in keeping up with the development of modern software systems.

5. Application to My Internship Project

My internship project is titled “Design and Implementation of an Automated CI/CD Pipeline for Web Application Deployment on AWS.”

The knowledge gained from the meetup can be applied to my project in the following ways:

  • Application Development: Apply API design principles when reviewing and developing Backend components of the Spring Boot web application.
  • System Integration: Understand how APIs support communication between different application components and external services.
  • Testing: Consider API testing as part of the software verification process to check request handling, response formats, and error handling.
  • Security: Pay attention to authentication, authorization, and data protection when designing application interfaces.
  • Documentation: Recognize the importance of clear API documentation to make the application easier to maintain and develop.

These concepts can support the development of a more organized and maintainable web application before integrating it into the automated CI/CD pipeline on AWS.

Through the Mini Meetup on August 22, 2026, I gained additional knowledge about APIs, Backend development, API design principles, and system integration.

These insights will support my continued learning and help me improve my understanding of Backend development while implementing the automated CI/CD pipeline for web application deployment on AWS.

These principles can be applied when designing and developing software systems in real-world environments.
