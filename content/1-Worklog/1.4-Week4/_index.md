### Week 4 Objectives

* Understand the fundamentals of Git and GitHub.
* Learn how to manage source code using Git.
* Organize the web application project in a Git repository.
* Prepare the source code repository for integration with AWS developer tools.

### Tasks to be carried out this week

| Day | Task | Start Date | Completion Date | Reference Material |
|-----| --- | --- | --- | --- |
| 1   | - Learn the fundamentals of version control systems. <br> - Understand the differences between Git and GitHub. | 09/05/2026 | 09/05/2026 | [Git Documentation](https://git-scm.com/doc) |
| 2   | - Review basic Git commands, including `git init`, `git status`, `git add`, and `git commit`. <br> - Understand how commits record source code changes. | 09/06/2026 | 09/06/2026 | [Git Reference](https://git-scm.com/docs) |
| 3   | - Create or review the GitHub repository for the CI/CD project. <br> - Configure the remote repository and check the local Git settings. | 09/07/2026 | 09/07/2026 | [GitHub Documentation](https://docs.github.com/en/repositories) |
| 4   | - Learn how to manage branches and push source code to GitHub. <br> - Review how to check repository status and resolve common Git configuration issues. | 09/08/2026 | 09/09/2026 | [GitHub Git Guide](https://docs.github.com/en/get-started/using-git) |
| 5   | - Verify that the project source code and required configuration files are present in the repository. <br> - Review the repository structure before configuring automated builds. | 09/10/2026 | 09/11/2026 | [GitHub Documentation](https://docs.github.com/en/repositories) |

### Week 4 Achievements

* Understood the basic concepts of version control and the roles of Git and GitHub.
* Learned how to track source code changes using Git.
* Understood how to create commits and push local changes to a remote repository.
* Reviewed the repository structure and identified the files needed for the CI/CD workflow.
* Prepared the source code repository for the subsequent AWS CodeBuild configuration stage.
