**On this page**, this worklog presents the activities carried out during the internship, focusing on designing and implementing an automated CI/CD pipeline for deploying a web application on AWS.

The internship is organized into 10 weeks, covering AWS fundamentals, application development, source code management, automated building and testing, deployment, pipeline integration, and project documentation.

**Week 1:** [Getting Familiar with AWS and Basic AWS Services](1.1-week1/)

**Week 2:** [Learning CI/CD Concepts and Designing the Workflow](1.2-week2/)

**Week 3:** [Preparing the Web Application and Development Environment](1.3-week3/)

**Week 4:** [Managing Source Code with Git and GitHub](1.4-week4/)

**Week 5:** [Writing Unit Tests and Preparing the Build Process](1.5-week5/)

**Week 6:** [Configuring AWS CodeBuild](1.6-week6/)

**Week 7:** [Preparing the AWS Environment for Deployment](1.7-week7/)

**Week 8:** [Configuring AWS CodeDeploy](1.8-week8/)

**Week 9:** [Integrating AWS CodePipeline](1.9-week9/)

**Week 10:** [Monitoring, Testing, and Completing the Internship Report](1.10-week10/)
