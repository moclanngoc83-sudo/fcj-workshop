### Week 2 Objectives

* Understand the concepts and benefits of Continuous Integration (CI) and Continuous Delivery/Deployment (CD).
* Learn the main stages of a CI/CD pipeline.
* Explore AWS developer tools used to automate application building, testing, and deployment.
* Design an initial CI/CD workflow for the internship project.

### Week 2 Achievements

* Understood the basic concepts of CI/CD and the benefits of automating software delivery.
* Identified the main stages of a CI/CD pipeline, from source code management to application deployment.
* Understood the roles of AWS CodePipeline, AWS CodeBuild, and AWS CodeDeploy.
* Designed an initial workflow connecting GitHub, AWS developer tools, and Amazon EC2.
* Established the technical direction for preparing the web application and implementing the pipeline in subsequent weeks.
