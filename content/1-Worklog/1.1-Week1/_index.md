### Week 1 Objectives

* Get acquainted with the internship environment and working procedures.
* Understand the fundamentals of cloud computing and Amazon Web Services (AWS).
* Become familiar with the AWS Management Console and basic AWS services.
* Identify AWS services that may be useful for deploying and managing a web application.

### Week 1 Achievements

* Understood the basic concepts of cloud computing and the main categories of AWS services.
* Became familiar with the AWS Management Console and the purpose of AWS CLI.
* Learned the basic concepts of Amazon EC2 and its role in hosting web applications.
* Identified the AWS services that will be studied in the CI/CD project.
* Established an initial understanding of the cloud environment and the technical knowledge needed for the following weeks.
